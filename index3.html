Terminal GitHub

Kuasai alur kerja Git langsung dari terminal futuristik Anda.

zsh - aether-glass
# Inisialisasi repositori lokal.
➜ ~ git init
# Menambahkan semua perubahan ke staging area.
➜ ~ git add .
# Menyimpan perubahan dengan pesan.
➜ ~ git commit -m "first commit"
# Mengatur branch utama ke 'main'.
➜ ~ git branch -M main
# Menghubungkan ke repositori GitHub.
➜ ~ git remote add origin [URL]
# Mengunggah kode ke GitHub.
➜ ~ git push -u origin main
