The Triad of the Web

Membangun rumah modern di dunia digital. Pahami struktur, gaya, dan interaksi yang membuat web hidup.

code

HTML: Fondasi

HyperText Markup Language. Ibarat struktur beton dan bata sebuah rumah. Ini memberikan bentuk dasar, dinding, dan ruangan untuk konten digital Anda.

<div class="rumah">
  <h1>Atap</h1>
</div>
palette

CSS: Estetika

Cascading Style Sheets. Ini adalah cat, dekorasi, dan desain interior. CSS membuat struktur dasar menjadi indah dan responsif di berbagai ukuran layar.

.rumah {
  warna: putih;
  gaya: modern;
}
bolt

JS: Interaksi

JavaScript. Ini adalah sistem kelistrikan dan pipa air. Memberikan fungsi nyata—menghidupkan lampu, membuka pintu, dan merespons tindakan pengguna.

saklar.on("klik", () => {
  lampu.nyala();
});
